# Task List

A desktop task management application built with Java Swing.

## Features

### Task Management

* Add new tasks
* Delete selected tasks
* Clear all tasks
* Add tasks by pressing Enter

### Task Completion

* Mark tasks as completed
* Unmark completed tasks
* Visual completion indicator (✓)

### User Interface

* Dark theme
* Scrollable task list
* Task counter
* Confirmation dialogs
* Error notifications

## Technologies

* Java
* Java Swing
* Object-Oriented Programming (OOP)

## Purpose

This project was created to practice GUI development, event handling, list management, and user interaction using Java Swing.

## Future Improvements
